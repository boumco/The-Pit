## Démo + Planification du sprint suivant

### Ce que nous avons fait durant ce sprint
> Lors de ce premier sprint, nous avons dans un premier temps chercher une idée de jeux.

L'idée est la suivante : 
Un jeux tout par tour basé sur la bourse
-> Le lore : On incarne un jeune qui est surendetté et qui doit trouver impérativement de l’argent sous 15 jours avant que l’huissier de justice viennent saisir son argent. Pour couvrir sa dette, le jeune homme décide d’utiliser le peu d’économie qui lui reste pour investir en bourse sur des entreprises.
-> Les entreprises qu’il choisit peuvent plus ou moins aléatoirement  gagner ou perdre en valeur.
-> Des événement aléatoire peuvent apparaître et influer sur les valeurs de certaines entreprise
-> Le but est donc de récolter 10k euros afin de rembourser sa dette

Le déroulé type du jeux est :
-> Le joueur commence avec son solde de départ qui est de 100 euros 
-> Lors d’un tour , le joueur peut : 
1. Acheter une action d’une entreprise
2. Vendre une action
3. Regarder le journal d’évenement 
4. Finir le tour
5. Savoir son capital
